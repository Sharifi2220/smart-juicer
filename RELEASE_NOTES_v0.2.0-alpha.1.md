# Smart Juicer v0.2.0-alpha.1

## GitHub pre-release

Tag: `v0.2.0-alpha.1`

This is a deliberately limited open-source alpha for a local observer, interactive task analysis, and passive Shadow Mode imports. It contains no active model routing or autonomous coding-agent execution.

## Included

- local read-only task analysis;
- explicitly imported metadata-only JSON/JSONL Shadow Mode;
- synthetic fixtures, regression tests, and TypeScript checking;
- experimental diagnostic inspector, wrapper, verifier, and benchmark helpers.

## Important limitations

Do not interpret this release as evidence of token or cost savings, production security, sandboxing, authorization, autonomous execution, or quality optimization. Missing observations remain unknown. `G1=FAIL/OFFEN` and `G2=OFFEN` for the active engine remain unchanged.

## Verification

The reproducible verification commands are:

```text
npm test
npm run check
```

The published pre-release does not imply production security, autonomous execution, model routing, or token/cost savings. No npm package is published.
